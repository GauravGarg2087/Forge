# Forge

A collaborative project management platform for development teams.

Forge brings project tracking, task management, team communication and code review workflows together in one place.

## Key Features

- Project and milestone management
- Task creation, assignment and tracking
- Team chat and direct messaging
- GitHub pull request integration
- Automated code reviews
- AI-powered task management through MCP
- AI agents for task triage and project summaries

## Architecture

Forge is designed as a microservices-based application with independent services for identity, project tracking, communication and AI integrations.

Each service manages its own data and communicates through well-defined APIs and events.
